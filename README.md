## Changelog

### Part 3 Enhancements (Current Release)
- **Interactive Elements:** Added a JavaScript lightbox gallery allowing users to click any image across the site for an expanded modal view.
- **Form Functionality & Validation:** Implemented rigorous client-side JavaScript form validation for both `enquiry.html` (volunteer/sponsor form) and `contact.html` (general messaging form), complete with regex checks for email and phone inputs and inline error handling.
- **Search Engine Optimization (SEO):** Added unique meta descriptions across all pages, structured heading hierarchies, semantic image alt attributes, a configured `robots.txt` crawler file, and an XML sitemap (`sitemap.xml`).
- **Deployment:** Published and deployed the live website on Netlify.
